# EODHD and Alpha Vantage provider assessment

Reviewed 27 November 2026 for [plugins #9](https://github.com/tailoralm/personal-ledger-plugins/issues/9) against [Personal Ledger provider SDK v1 at f145429](https://github.com/tailoralm/Personal-Ledger/blob/f145429702c100bdeeb5b4311b92f53db6bb0f13/docs/market-data-provider-v1.md). Both integrations require a broker contract change. This review used published vendor documentation. Account-specific feed availability, response shapes and entitlements still need verification with the intended account before release.

## EODHD

**Release blocker.** The first-party REST API on `https://eodhd.com` requires `api_token` in the query. The search, EOD and live routes also need one variable path segment. Core v1 injects Bearer or a lower-case `x-*` header only and approves literal HTTPS GET paths. The official SDK configures the same REST token. Hosted MCP v1 uses a query key and v2 uses OAuth for a separate MCP protocol. WebSocket feeds are also outside the GET broker contract. The reviewed sources establish no first-party REST header alternative for the operations below. [Authentication and OpenAPI scheme](https://course.eodhd.com/lessons/api-anatomy-of-a-request), [REST quick start](https://eodhd.com/financial-apis/quick-start-with-our-financial-data-apis), [Official SDK](https://eodhd.com/financial-apis/node-js-typescript-sdk-for-eodhd-financial-apis), [Hosted MCP](https://eodhd.com/financial-apis/mcp-server-for-financial-data-by-eodhd), [WebSocket feeds](https://eodhd.com/financial-apis/new-real-time-data-api-websockets)

| Operation | First-party route and conditional starting scope |
| --- | --- |
| Search | `GET /api/search/{query_string}` with a ticker, name or ISIN. Use the optional exchange, type and result limit where applicable. A registered Free key can use search. |
| Metadata | Use the exact code and exchange from search or `GET /api/exchange-symbol-list/{exchangeCode}` with `symbols` and `fmt=json`. Confirm exact matches and required currency, type, MIC and timezone before returning candidates. `GET /api/exchanges-list/` supplies venue reference data. `GET /api/fundamentals/{ticker}` is a separate paid feed at 10 credits and is unnecessary for basic listing metadata. |
| Latest | Start with the newest completed daily bar from `GET /api/eod/{symbol}` using a bounded window around the last session. The scalar `last_close` response alone lacks the session date. The alternative `GET /api/real-time/{ticker}` is a delayed snapshot with a timestamp and optional `s` multi-symbol input. The Free comparison lists 15-minute delayed stock data. Confirm the listing and entitlement before offering this feed. |
| History | `GET /api/eod/{symbol}?period=d&fmt=json&from=YYYY-MM-DD&to=YYYY-MM-DD` returns one symbol per call with inclusive bounds. Use host date windows. Paid `GET /api/eod-bulk-last-day/{exchangeCode}` covers a single market date and can be large. Omit it from the initial package. |

[Search](https://eodhd.com/financial-apis/search-api-for-stocks-etfs-mutual-funds), [Exchange and symbol metadata](https://eodhd.com/financial-apis/exchanges-api-list-of-tickers-and-trading-hours), [Fundamentals](https://eodhd.com/financial-apis/stock-etfs-fundamental-data-feeds), [EOD](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes), [Delayed quotes](https://eodhd.com/financial-apis/live-ohlcv-stocks-api), [Paid bulk](https://eodhd.com/financial-apis/bulk-api-eod-splits-dividends)

**Coverage, quota and cost.** Free lists one year of daily history for global stocks and ETFs and 20 API credits per day. EOD Historical All World lists full available history, including delisted listings and bulk, at $19.99/month at review. The plan comparison advertises 30+ years, and the EOD docs show some older US series. Depth depends on the listing and can have gaps. The exchange list includes Nasdaq and NYSE under `US`, Xetra `XETRA`, London `LSE`, Paris `PA` and Lisbon `LS`. Verify stock and ETF listings individually, including cross-listings. The suffix `.US` alone cannot identify the MIC. [Plans](https://eodhd.com/help/plans), [Pricing and coverage](https://eodhd.com/pricing), [Exchanges](https://eodhd.com/list-of-stock-markets), [Historical depth](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes)

Start with `batchSize: 1`, `pagination: false` and one credit per attempt for each single-request operation in the starting scope. A metadata lookup requiring a second request must be modeled as separately charged work or use verified venue metadata already available to the host. Delayed snapshots cost one credit per symbol. Use a conservative maximum-batch cost if later enabled because core charges the declared cost on each attempt, including partial batches. Paid bulk costs 100 for a whole exchange and 100 plus the number of specified symbols for filtered price calls, per the bulk API and limits reference. Use an editable local default of 20 credits per UTC day at 00:00, concurrency one and a conservative 5 requests/minute. EODHD lists 1,000 requests/minute and typically 100,000 credits/day on paid core plans. Treat signup credits as temporary and reduce local limits when the token is shared across clients. [Rate limits and costs](https://eodhd.com/financial-apis/api-limits), [Quota resets](https://eodhd.com/help/limits), [Measured bulk pricing](https://eodhd.com/financial-apis/bulk-api-eod-splits-dividends)

**Data rights.** The personal-plan terms and vendor guidance permit eligible non-professional users to store raw and normalized data, keep private backups and provenance, display data privately to themselves and retain downloaded data after cancellation or downgrade. New data and revisions still require an entitled plan. Shared display, redistribution of data or derived outputs, and business use need applicable commercial permissions. Limit a personal integration to the account owner's own workspace and private use. Publish code and synthetic fixtures only. [Terms](https://eodhd.com/financial-apis/terms-conditions), [Personal display](https://eodhd.com/help/personal-use), [Storage and retention](https://eodhd.com/help/storage)

## Alpha Vantage

**Release blockers.** Each operation below uses the literal `GET https://www.alphavantage.co/query` and requires the `apikey` query credential. The reviewed first-party REST docs list no compatible Bearer or `x-*` header alternative. The official MCP service uses a separate OAuth flow and MCP tool calls. The EULA permits personal, non-commercial platform use and display of its software on devices the user owns or controls. It does not expressly grant durable retention of downloaded prices or their display in a separate application. Verify permission for normalized observations in Ledger, personal UI display, database and export copies, backups and retention after termination, including exchange-specific conditions. Obtain written terms for any unclear scope and separate commercial authorization where required. A paid key or exchange entitlement alone does not establish those rights. [REST API](https://www.alphavantage.co/documentation/), [Official MCP](https://mcp.alphavantage.co/), [Terms §§2–7](https://www.alphavantage.co/terms_of_service/), [US exchange data policies](https://www.alphavantage.co/realtime_data_policy/)

| Operation | `function` and conditional starting scope |
| --- | --- |
| Search | `SYMBOL_SEARCH` with `keywords` for ticker or name. ISIN lookup is undocumented. Reject that search mode unless a supported upstream capability is verified. |
| Metadata | Reuse search metadata only for an exact returned upstream `symbol`. Confirm listing exchange, currency and timezone before approval. `OVERVIEW` and `ETF_PROFILE` are separate descriptive datasets. Use only with verified endpoint and listing entitlement. Neither is a cross-market listing identifier. |
| Latest | `GLOBAL_QUOTE` with one `symbol`, updated after each trading day by default. An entitled premium account can request US `entitlement=realtime` or `entitlement=delayed` (15 minutes). Start with EOD only. Premium `REALTIME_BULK_QUOTES` accepts up to 100 comma-separated US symbols and requires the corresponding exchange entitlement. |
| History | `TIME_SERIES_DAILY` with one `symbol` and `outputsize=compact` gives up to 100 daily observations, not 100 calendar days. `outputsize=full` is premium and advertises 25+ years where available. `TIME_SERIES_DAILY_ADJUSTED` is premium and supplies an adjusted close alongside raw OHLC. The daily API has no date bounds or date cursor. Filter the returned series locally and make clipped or unavailable ranges visible. |

[Search, quotes, raw and adjusted daily bars, ETF profiles](https://www.alphavantage.co/documentation/), [Free key support](https://www.alphavantage.co/support/api-key/), [Premium and entitlement activation](https://www.alphavantage.co/premium/)

**Coverage, quota and cost.** Official examples include US equity `IBM`, US ETF `QQQ`, London equity `TSCO.LON` and Xetra equity `MBG.DEX`. Search advertises global stocks and ETFs, but the reviewed docs do not establish entitlement to particular European ETFs or comprehensive exchange coverage, including Paris or Lisbon. Verify US and European stock and ETF examples for each proposed MIC, operation and plan before declaring support. Prefer exact upstream symbols over guessing suffix aliases or deriving a MIC from a region. Limit Free to confirmed endpoints and compact history, and expose premium full history, adjusted daily, US delayed/realtime and US bulk as unavailable without the applicable entitlement. A paid history capability also needs a broker-compatible response strategy. Filtering happens after the 1 MiB HTTP body cap, and splitting a logical range would refetch the same full series. Measure response bounds before offering full history. If the full response cannot fit, use a documented bounded endpoint or a reviewed host contract change. [API reference](https://www.alphavantage.co/documentation/), [Premium activation](https://www.alphavantage.co/premium/)

Start with `batchSize: 1`, `pagination: false` and one credit per single HTTP request. Free is 25 requests/day for eligible datasets. The separate verified open-source or educational offer requires vendor approval. Premium lists no daily cap, with priced tiers by requests/minute and specific exchange entitlements. Check current checkout pricing and choose only the tier needed for the intended feeds and throughput. Use an editable local starting budget of 25 attempts/day, 5 requests/minute and concurrency one. UTC midnight is a local budget boundary pending verification of the actual vendor reset policy. Leave headroom for other clients and reduce or reconfigure limits after observing actual usage. For paid bulk, verify quota accounting for the subscribed key before declaring a credit cost. [Support quotas](https://www.alphavantage.co/support/api-key/), [Paid plans](https://www.alphavantage.co/premium/)

## Conditional implementation path

1. **Version and approve the network contract.** Coordinate with [core #63](https://github.com/tailoralm/Personal-Ledger/issues/63) and [#64](https://github.com/tailoralm/Personal-Ledger/issues/64). Add an explicit host-owned query credential slot with one fixed parameter name per route (`api_token` or `apikey`). Reject guest-supplied duplicates of the reserved name, including case variants. Inject one encoded credential at dispatch after route/approval and secret checks. Keep the final URL, query credential, echoed values and upstream error bodies out of guest-visible data, logs, telemetry, persisted requests and errors. Retain HTTPS, public DNS pinning, URL size checks on the final request, redirect rejection and exact-release approval.
2. **Scope route parameters.** For EODHD, the host contract also needs fixed route templates with a declared, required single-segment argument. The manifest specifies the HTTPS origin and literal prefix, for example `/api/eod/{symbol}` or `/api/search/{term}`. The HTTP plan carries the raw argument separately. Validate bounded ticker/exchange alphabets and bounded text for search. Reject separators, dot segments, control characters and pre-encoded or ambiguous segments. Encode once and verify the final origin and segment boundaries before dispatch. Approve the exact template and credential slot. For Alpha Vantage keep the literal `/query` path and bind each route to a fixed, approved `function` value so guest code cannot select arbitrary upstream operations. Show these constraints in package approval. Add negative contract tests for credential override, URL leakage and route escapes. Mirror the reviewed schemas and SDK here after core lands.
3. **Verify identity, timing and normalization.** Resolve an approved stable listing using exact symbol, exchange, currency and IANA timezone. Distinguish cross-listings, ETFs, unsupported and delisted symbols. If a quote response lacks currency, market zone or close time, obtain them from verified listing and session information through a reviewed host input or documented provider metadata. V1 hooks receive no approved mapping or market calendar. A quote without enough evidence stays unavailable. Use an upstream timestamp or verified session close including DST and early closes, never retrieval time, for the exchange-local market date. For confirmed `GBp`/`GBX` listings, shift the decimal two places to GBP per listed unit, and verify separately against a genuine GBP listing. Preserve decimal precision, including EODHD JSON numbers, and output canonical decimal strings, `DD/MM/YYYY` market dates, UTC timestamps with milliseconds and `per-share` price units. Use raw OHLC for raw history and avoid substituting an adjusted close for a raw close or for a fully adjusted candle. Omit unsupported adjustment bases and optional volume when its basis is unsuitable. Verify corporate-action days, market holidays and weekends, and leave absent sessions empty. A latest EOD quote retains the date of its last actual session. Check requested ranges for missing or clipped coverage and avoid inventing zero prices or rolling observations forward.
4. **Expose limits and failures.** Keep plan-dependent features disabled until verified. If a capability varies by tier or basis, use a host-side entitlement check before enqueueing and surface it in Settings. The pinned manifest declares capabilities per operation, and its hooks receive no plan setting. Preserve typed errors for invalid input, credentials, entitlement refusal and invalid data. For Alpha Vantage classify HTTP 200 error envelopes, including `Note`, `Information` and `Error Message`, by validated meaning. A quota notice can become `rate-limited`, while an entitlement message must be terminal. For EODHD distinguish bad credentials, declined entitlements, unknown tickers and valid empty windows. Core handles HTTP 429 and validated `Retry-After`. Count each dispatch, retry and page, and report partial completion via broker job status. Avoid retrying a confirmed daily quota exhaustion repeatedly before the next window.
5. **Schedule, test and package.** Start manual. Offer editable daily refresh after publication in each listing's market timezone. EODHD documents release typically two to three hours after close. After midnight local time is a conservative starting point, subject to verifying publication and handling scheduled weekend runs within the budget. Use the host to compute rolling date windows. The pinned schedule stores literal ranges. Coordinate settings, valuation compatibility and release work with core [#65](https://github.com/tailoralm/Personal-Ledger/issues/65), [#66](https://github.com/tailoralm/Personal-Ledger/issues/66), [#67](https://github.com/tailoralm/Personal-Ledger/issues/67) and [#68](https://github.com/tailoralm/Personal-Ledger/issues/68). After the release gates clear for a vendor, add its own package and host key slot. Test its real QuickJS hooks and broker with synthetic fixtures and mock transport, including quota, provenance, entitlement, payload size and approved-listing checks. Build reproducible ZIPs and add provider catalog entries under the existing release process.
